# Genetic TSP

Веб-приложение для визуализации работы генетического алгоритма при решении задачи коммивояжёра (TSP).

Проект демонстрирует процесс поиска оптимального маршрута между заданными городами с использованием генетического алгоритма. Пользователь может изменять параметры алгоритма, запускать процесс оптимизации и наблюдать за изменением лучшего найденного маршрута в режиме реального времени.

## Возможности

- Визуализация расположения городов и построенного маршрута.
- Настройка параметров генетического алгоритма.
- Отображение процесса оптимизации в реальном времени.
- Отображение лучшего найденного маршрута и его длины.
- История поколений с указанием лучшей длины маршрута.
- График сходимости алгоритма, отображающий изменение длины маршрута по поколениям.

## Установка и запуск

Для запуска проекта необходимы установленные Python и Node.js.

### 1. Клонирование репозитория

```bash
git clone https://github.com/lleenzz/genetic-tsp.git
cd tsp-genetic-app
```

### 2. Запуск Backend

Перейдите в папку backend:

```bash
cd backend
```

Установите зависимости:

```bash
python -m pip install fastapi uvicorn
```

Запустите сервер:

```bash
uvicorn main:app --reload
```

Backend будет доступен по адресу:

```text
http://localhost:8000
```

### 3. Запуск Frontend

Откройте второй терминал и перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm run dev
```

После запуска приложение будет доступно по локальному адресу, указанному Vite в терминале.

## Тестирование

Для проверки корректности работы генетического алгоритма используются модульные тесты на pytest.

Установите pytest:

```bash
python -m pip install pytest
```

Перейдите в папку backend и выполните:

```bash
python -m pytest
```

Тесты проверяют основные функции генетического алгоритма: генерацию городов, вычисление расстояний и длины маршрута, формирование популяции, отбор, скрещивание, мутацию и работу алгоритма в целом.
