# Genetic TSP

Веб-приложение для визуализации работы генетического алгоритма при решении задачи коммивояжёра (TSP).

Проект демонстрирует процесс поиска оптимального маршрута между заданными городами с использованием генетического алгоритма.

## Возможности

- Визуализация городов и текущего маршрута.
- Настройка параметров генетического алгоритма.
- Отображение процесса оптимизации в реальном времени.
- История поколений с указанием лучшей длины маршрута.
- График сходимости, отображающий изменение результата алгоритма.

## Используемые технологии

- **Frontend:** React, JavaScript, SCSS.
- **Backend:** Python, FastAPI.

## Статус проекта

Проект находится в разработке.
